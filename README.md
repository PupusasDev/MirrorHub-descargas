# Mirror Hub — descargas

Ve y controla varios teléfonos Android desde tu computadora, en una sola ventana.

**Página oficial:** https://pupusasdev.com/apps/mirror-hub

## Descargar

Andá a **[Releases](../../releases/latest)** y descargá:

- **`MirrorHub-<versión>-setup.exe`**: instalador para Windows 10/11 (64 bits). No pide permisos de administrador.
- **`MirrorHub-<versión>-windows-x64.zip`**: versión portable. Descomprimí y abrí `MirrorHub.exe`.

> 🛡️ Al instalar, Windows puede mostrar «Editor desconocido» porque la app es nueva y gratuita.
> Pulsá **Más información → Ejecutar de todas formas**.

## Cómo empezar

1. En el teléfono, activá **Opciones de desarrollador → Depuración USB**.
2. Conectalo con el cable y aceptá el aviso que aparece en pantalla (o usá «Conectar por Wi-Fi (QR)», Android 11 o superior).
3. Abrí Mirror Hub y pulsá **«Mostrar»**.
